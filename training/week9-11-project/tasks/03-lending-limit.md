# タスク3: 貸出上限ルール（1人が同時に借りられる冊数を制限）

**難易度**: ★★☆（**既存の貸出処理に手を入れる**。影響範囲の見極めが本番）
**AI利用区分**: ✅ 全面解禁。ただし説明責任を伴う。

---

## 1. 背景（なぜこの機能が要るか）

いまは1人が何冊でも借りられてしまいます。運用ルールとして「**1人が同時に借りられるのは最大5冊まで**」を設けたい、という要望です。すでに5冊借りている人が6冊目を借りようとしたら、断る必要があります。

> このタスクは、タスク1・2と違い**新規追加ではありません**。既存の「貸出処理（`lend`）」に手を入れます。週7で学んだ「**壊さず直す・影響範囲を見る**」がそのまま問われます。

---

## 2. 仕様（受け入れ基準）

### ルール
- 1人（member）が**同時に借りている（未返却の）冊数が5冊以上**のとき、新たな貸出は**断る**。
- 断るときは、業務ルール違反として **409 Conflict**（既存の `BusinessRuleException`）を返す。
- 上限は「5」だが、**マジックナンバーを直書きせず**、定数などで意図が分かる形にする（既存の `LENDING_PERIOD_DAYS` の書き方に倣う）。

### 受け入れ基準
- [ ] 未返却が5冊未満の人は、今まで通り借りられる
- [ ] 未返却が5冊の人が借りようとすると、409 で断られ、**貸出記録は作られない**
- [ ] 上限のチェックは、在庫チェックや借り主の実在チェックと**矛盾なく**動く
- [ ] 単体テスト（Service層）を足し、`./gradlew test` が**全緑**
- [ ] **既存の貸出テストを壊していない**（正常な貸出・在庫切れの拒否など）

---

## 3. 着地点のヒント（週6の読解 + 週7の影響範囲）

`LendingService.lend` に手を入れます。**追加する前に、影響範囲を考えてください**（週7の作法）:

- 「その人が今何冊借りているか」を数える必要がある → `LendingMapper` に「未返却の貸出件数を数える」メソッドを足す（`SELECT COUNT(*) ... WHERE member_id = ? AND returned_at IS NULL`）。
- そのカウントを `lend` の中で確認し、上限以上なら例外を投げる。
- **どこに差し込むか**が重要: 在庫を減らす（`decrementAvailable`）**前**に上限チェックを置くべき。後にすると、上限で断るのに在庫だけ減ってしまう不整合が起きる（←これが影響範囲の罠）。

> AIに「貸出上限を実装して」と頼むと、上限チェックを入れてくれるでしょう。でも**「在庫を減らす前に置くか、後に置くか」**まで正しく判断できるかは別問題。ここは自分で、処理の順序と影響を確かめてください。

---

## 4. 動作確認（自分でやってから、PRを出す）

サンプルデータでは、1人が同時に5冊は借りていません。**上限に達する状況を自分で作って**確認します。
```bash
# 例: member 1 に、上限まで貸出を繰り返す（bookId を変えながら5回）
curl -X POST http://localhost:8080/api/lendings -H 'Content-Type: application/json' -d '{"bookId":2,"memberId":1}'
# …これを在庫のある本で繰り返し、5冊目まで成功させる…
# 6冊目 → 409 が返り、貸出記録が増えないこと
curl -i -X POST http://localhost:8080/api/lendings -H 'Content-Type: application/json' -d '{"bookId":5,"memberId":1}'
```
> 何冊借りているかは `GET /api/members/1/lendings` で確認できます。

---

## 5. レビュー観点（出す前に自分でも確認）

- **チェックの位置**: 上限チェックが**在庫を減らす前**にあるか（順序を間違えると在庫だけ減る不整合）。
- **数え方が正しいか**: 「未返却の」冊数を数えているか（`returned_at IS NULL`）。返却済みまで数えていないか。
- **マジックナンバー**: `5` が直書きされていないか。意図が分かる定数になっているか。
- **リグレッション**（週7）: 既存の貸出テストが全部緑のままか。上限に達していない人の貸出を壊していないか。
- **テストの網羅**（週8）: 「4冊目は借りられる／5冊目で断られる」の**境界**を確かめているか。
