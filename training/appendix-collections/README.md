## 1. 3つの違い（ここだけ掴めば十分）

3つとも「複数のものを入れる箱」です。違うのは**何を大事にしているか**だけ。

| | 何を大事にしているか | 同じものを入れると | 順番 | ひとことで |
|---|---|---|---|---|
| **List** | **並び順** | そのまま何個でも入る | ある | **並べる** |
| **Set** | **重複しないこと** | 1個にまとめられる | 無い（保証されない） | **種類を数える** |
| **Map** | **キーと値の対応** | 同じキーなら上書き | 無い（保証されない） | **引く** |

> 用語メモ: **コレクション** … List・Set・Map のような「複数のものをまとめて持つ入れ物」の総称。
> 用語メモ: **キー** … Map で値を取り出すための名札。`counts.get("リーダブルコード")` の `"リーダブルコード"` がキー。

### たとえ話

- **List** … レシート。買った順に上から並び、同じ商品が2回出てきてもそのまま2行。
- **Set** … 福引の抽選箱に入れる「商品の種類」。同じ商品を何個買っても、種類としては1つ。
- **Map** … 電話帳。名前（キー）を引くと番号（値）が出る。名前が分かっていれば一発。

## 2. どれを選ぶか（実務で迷ったとき）

**「聞かれていることは何か」で決まります。** 入れ物を先に決めるのではなく、答えたいことから逆に選びます。

| 答えたいこと | 選ぶもの | なぜ |
|---|---|---|
| 「借りた順に全部見せて」 | **List** | 順番そのものが答えの一部 |
| 「最後に借りた3冊は？」 | **List** | 位置で取り出したい |
| 「何種類の本を借りた？」 | **Set** | 同じ本を何度借りても1種類 |
| 「この本、借りたことある？」 | **Set** | 有無だけ分かればよい（速い） |
| 「本ごとの貸出回数は？」 | **Map** | 本（キー）に数（値）をぶら下げる |
| 「会員IDから氏名を引きたい」 | **Map** | 引くための表 |

> **迷ったら List で構いません。** いちばん素直で、あとから Set や Map に移せます。「重複が邪魔になった」「毎回ぐるぐる探していて遅い」と気づいたときが、乗り換えどきです。最初から完璧に選ぼうとしなくて大丈夫。

## 3. よく使う操作（早見表）

```java
import java.util.*;

// ---- List: 並べる ----
List<String> list = new ArrayList<>();
list.add("A");              // 末尾に足す
list.get(0);                // 0番目を取る（先頭は0）
list.size();                // 件数
list.contains("A");         // 入っているか
for (String s : list) { }   // 順番に全部見る

// ---- Set: 重複を消す ----
Set<String> set = new HashSet<>();
set.add("A");               // 足す。すでにあれば増えない
set.add("A");               // ← 何度足しても1個のまま
set.size();                 // 種類の数
set.contains("A");          // 入っているか（List より速い）
Set<String> kinds = new HashSet<>(list);  // ★ Listから重複を消す一番速い書き方

// ---- Map: 引く ----
Map<String, Integer> map = new HashMap<>();
map.put("A", 1);            // キー"A"に値1を対応させる
map.get("A");               // → 1（キーが無ければ null）
map.getOrDefault("A", 0);   // → キーが無ければ 0 を返す（null を気にしなくていい）
map.containsKey("A");       // キーがあるか
for (Map.Entry<String, Integer> e : map.entrySet()) {   // 全部見る
    e.getKey();
    e.getValue();
}
```

> **数えるときの決まり文句**: `map.put(key, map.getOrDefault(key, 0) + 1);`
> 「いまの数（無ければ0）に1を足して入れ直す」。カウントはほぼこれで書けます。覚えておくと得です。
