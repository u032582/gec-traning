# 週12: 総仕上げ・評価 — 短い仕様から、一人でやり切る

いよいよ最終週です。3ヶ月かけて積み上げてきた力を、**一つの総合演習**で確かめます。
これまでの週は、課題に「着地点のヒント」や「受け入れ基準の詳細」が付いていました。**今週は、あえてそれを外します**。現場で実際に渡されるのは、たいてい**短い仕様**だけです。そこから自分で調べ、実装し、テストし、PRを出し、レビューに対応する——その一連を**一人でやり切れるか**が、この研修の最終確認です。
全体の進め方・AI利用ルール・質問テンプレート・日報フォーマットは、[研修トップのREADME](../README.md) を参照。

> この週は「新しいことを教わる週」ではありません。**これまで身につけたことを、支えを外した状態で発揮する週**です。詰まってよいです。大事なのは、詰まったときに**報連相できるか**、レビュー指摘に**向き合えるか**まで含めて自走できること。

---

## 1. この週の狙い（到達目標）

> **短い仕様から、調査〜実装〜テスト〜PRまで、報連相とレビュー対応も含めて自走できる。**

これは、研修全体の最終到達点そのものです。

> **「AIを相棒に、既存のシステム（自分が書いたのではない、大きめのコードベース）に参画し、仕様を読み、影響範囲を見極めて安全に改修・小機能追加を行い、テストを書き、PRを出し、レビューの往復をこなして取り込まれるまでを、一人で回せる」**

今週は、この状態に達したかを**実演で確認**します。

---

## 2. AI利用区分（この週のルール）

✅ **全面解禁（現場想定）。** ただし**説明責任は常に伴う**——ここは3ヶ月を通じて一貫しています。

- ✅ 調査・実装・テスト・PR本文・レビュー対応、すべてAIを使ってよい
- ✅ ただし出したものは自分の言葉で説明でき、判断の主語は常にあなた
- 🚫 「AIがこう言った」は、仕様の解釈にもレビュー返答にも使えない

> 最終週なので、あらためて。AIを使うこと自体は現場では当たり前。差がつくのは「**AIの出力に責任を持ち、自分の判断を上に置けるか**」。この3ヶ月で鍛えたのは、まさにそこです。

---

## 3. 総合演習（この週の主課題）

課題は1本。**短い仕様**だけ渡します。ヒントは最小限です。

→ **[exercises/final-task.md](exercises/final-task.md)（総合演習: 貸出の延長機能）**

この演習では、これまでの全部を自分で組み立てます:

| 使う力 | どの週で身につけたか |
|---|---|
| 既存コードを読んで着地点を決める | 週6（読解） |
| 影響範囲を見て壊さず実装する | 週7（安全な改修） |
| 意味のあるテストを付ける | 週8（テスト品質） |
| AIと協働し、生成物を検証・説明する | 週5（AI協働） |
| ブランチ→PR→レビュー往復 | 週7・週9〜11 |
| 詰まったときの報連相 | 全期間 |

> **今週は「着地点のヒント」を出しません。** どこに足すか・どう影響を見るかは、週6で作った読解の地図と、自分の目で決めてください。それができることの確認が、この週の目的です。

---

## 4. 進め方（自分で組み立てる）

これまでのサイクルを、**自分で回してください**（もう手順を細かく指示しません）。おおまかには:

1. 仕様を読み、**分からない点・決めるべき点を洗い出す**（曖昧なら質問してよい＝報連相）。
2. 既存リポを調査し、**着地点と影響範囲**を自分で決める。
3. ブランチを切り、AIと協働で実装＋テスト。
4. 自分で受け入れ基準（動作確認・全テスト緑）を満たす。
5. PRを出し、レビューの往復に対応する。
6. 3ヶ月の振り返りを書く（§5）。

> 詰まったら抱え込まないこと。**「どこまで調べて、何が分からないか」を添えて質問する**——これも評価対象（報連相）です。詰まること自体は減点ではありません。

---

## 5. 3ヶ月の振り返り（もう一つの提出物）

総合演習と並んで、**3ヶ月の振り返り**を書きます。テンプレートは [exercises/retrospective.md](exercises/retrospective.md) にあります。
「何ができるようになったか」「AIとの付き合い方はどう変わったか」「現場で気をつけたいこと」を、自分の言葉で。これは評価面談の材料にもなります。

## 6. この週の完了判定（自己採点 ＋ 評価面談）

- [ ] 総合演習を、**着地点も影響範囲も自分で決めて**実装した

- [ ] PRを出し、レビューの往復に**自分の言葉で**対応した
- [ ] 詰まった場面で、報連相（何を調べ何が分からないか添えて質問）ができた
- [ ] 3ヶ月の振り返りを書いた

全部✅になり、評価面談でこれらを実演・説明できれば——**研修修了です。** 3ヶ月、おつかれさまでした。「AIを相棒に、既存システムに参画して安全に前へ進められる新人」に、あなたはなりました。ここからが現場のスタートです。
