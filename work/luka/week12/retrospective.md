# 3ヶ月の振り返り

研修の締めくくりに、3ヶ月を振り返ります。これは評価面談の材料にもなります。**自分の言葉で**書いてください。正解はありません。正直に書くほど、次に活きます。

> 書き方: 各項目に2〜4行。うまく書こうとしなくてよい。「できるようになったこと」も「まだ不安なこと」も、両方あって当たり前です。

---

## 1. できるようになったこと

3ヶ月前の自分と比べて、何ができるようになりましたか。具体的な場面で。

```
  以前はただコードの羅列を目で追っているだけ、という感覚が強かったですが最近はきちんと解読出来るようになった感覚がします。
  実装はAIの補助も多いですが、以前より出力を読んで判断できるようになった、という実感があります。

```

---

## 2. AIとの付き合い方は、どう変わったか

第1フェーズ（手書き）→ 第2フェーズ（AI協働）を通じて、AIへの向き合い方はどう変わりましたか。

```
  AIにコードを出してもらうばかりのやり方だと説明責任があるとはいえ、
  それさえもAIにこの解釈で合っているかを聞いたり、ヒントを出してもらっていたので身についた感じがしませんでした。
  なので後半は間違えてもいいからまず自分でコードを書いて、AIに確認させて解説を求める形にしました。第一フェーズのやり方をずっと通していけばよかったかなと思いました。


```

---

## 3. 一番苦労したこと・つまずいたこと

どこで一番詰まりましたか。それをどう乗り越えましたか（乗り越えられていないなら、それも正直に）。

```
週１の基礎部分です。基礎ということで今ほど複雑ではないはずなのに一番難しかったように思います。
どこまでAIに聞けばいいのかもわからなかった時期なのでその影響もあると思います。
map/set/listあたりはその後の課題に出てきてないうえに苦手意識だけが強いままなので、
乗り越えられていない、というより忘れている可能性があります。

```

---

## 4. 「動き方」で身についたこと（技術以外）

報連相・質問の仕方・レビューへの向き合い方など、技術以外で身についたことは。

```
レビュー往復の課題の説明にも、AIからも、あくまでレビューに対しての指摘である、ということを言葉にしてくれていたので、
AIと共に修正して説明することが出来ました。
メンタルが弱い自覚はあるので、一番不安な部分でしたが良い経験になったと思います。

```

---

## 5. 現場に出て、気をつけたいこと

配属先で、自分が特に気をつけたいこと・伸ばしたいことは。

```
週２の課題であるSQLで、WHEREの付け忘れは全行書き換えや全削除に繋がる、というのがとても印象的だったので、
とにかく取り返しのつかないミスだけはしないよう気を付けたいです。
伸ばしたいことは、AIを使わなくてもスラスラコードを組み立てられる力、です。

```

---

## 6. まだ不安なこと（正直に）

これは減点材料ではありません。**不安を言語化できること自体が力**です。現場で助けを求める起点になります。

```
このコードは何をしているか、どうしてその書き方なのか、はまだ完璧に理解して説明できると断言はできません。
今まで課題を進めてきて、全く何も身につかなかったわけではありませんが、
間違いを恐れる性格故か、自分の中で完全に答えが出し切る前にAIに確認したり、ヒントをもらっていたりしていたのです。
AI無しで答えを出す状況になったら、おそらく言葉に詰まると思います。

```
